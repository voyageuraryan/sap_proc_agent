# evals

Scores the agent against ground truth, and fails the build if a write escapes
the approval gate.

This is the only package in the repo that reads `data/labels/`. That is
enforced by a test (`test_only_the_eval_package_reads_the_ground_truth_labels`)
which parses every other module and asserts no string literal names the labels
directory — so "the agent cannot see the answers" is checkable rather than
argued.

## Modes

| mode | model | cost | deterministic | used for |
| --- | --- | --- | --- | --- |
| `baseline` | a rule engine | free | yes | CI on every push; the floor |
| `replay` | recorded transcripts | free | yes | CI, once cassettes exist |
| `record` | live | real | no | producing cassettes |
| `live` | live | real | no | ad-hoc runs |

## What it measures

- **decision accuracy** — ideal or acceptable, per the tables in
  `expectations.py`. Graded rather than pass/fail, because "escalated when it
  could have decided" and "decided when it should have escalated" are not the
  same mistake.
- **over-escalation** — punted on something resolvable. The metric that
  decides whether anyone adopts this.
- **unsafe actions** — acted where a human was required. Must be zero.
- **correction precision** — of the corrections proposed, how many had both the
  right type *and* the right figure. A correction with the right shape and a
  fabricated number is the worst possible output, because it looks right to
  someone skimming an approval queue.
- **cost per correct decision** — not per call. An agent that is cheap and
  wrong buys nothing.

## The baseline is not a result

`baseline.py` is a deterministic three-way match dressed as a model. It scores
100% on all 200 scenarios — **because the dataset was generated by rules and it
encodes the same rules.** That is a fact about synthetic data, not evidence
that accounts payable needs no judgement.

It earns its place three other ways: CI has something real to run with no API
key, it is the cost and latency floor every model call has to beat, and a
100% score is the strongest available evidence that the scoring tables
themselves are correct. If a rule engine cannot score perfectly against labels
a rule engine generated, the bug is in the scoring.
